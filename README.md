### 🧭 Sobre mí

Hola, soy Michael 👋 Desarrollador full-stack en formación en **Campuslands** (Colombia). Construyo productos web de punta a punta: APIs sólidas, bases de datos bien diseñadas e interfaces claras.

- 🎓 Dos rutas de formación: **Desarrollo de Sistemas** y **Desarrollo de Sistemas con IA** (etapa lectiva con **Globant**)
- ⚙️ Backend con **Java + Spring Boot**: seguridad con JWT, permisos por rol, APIs REST
- 🗄️ Modelado y normalización en **PostgreSQL** y **MySQL**: procedimientos, triggers, ETL
- 🖥️ Frontend con **JavaScript / TypeScript**, Web Components y React
- 🤖 Automatización e IA con **n8n** y Gemini
- 🍈 Fruta del Diablo: *Full Stack no Mi*. Su debilidad: los bugs de CSS a las 2 AM
