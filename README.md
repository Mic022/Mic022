### 🧭 Bitácora del Log Pose

Navego entre dos rutas de formación en Campuslands — **Desarrollo de Sistemas** y **Desarrollo de Sistemas con Inteligencia Artificial**, esta última con etapa lectiva a bordo del barco de **Globant**.

Mi tesoro no es el One Piece — es construir productos web de punta a punta: interfaces claras, APIs sólidas y bases de datos que no se caen al primer Buster Call.
